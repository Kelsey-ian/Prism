✨ Prism 棱镜 — 现代化音视频图像格式转换器
基于 FFmpeg 二次开发的轻量、高性能媒体格式转换工具


---
📖 项目简介
Prism（棱镜） 是一款基于原生 FFmpeg 深度二次开发的现代化媒体格式转换器。摒弃传统转换工具冗余、卡顿、兼容性差的痛点，聚焦音频、视频、图片全品类日常格式转换场景，保留 FFmpeg 强悍的编码解码能力，同时优化交互逻辑与转换性能，支持全平台硬件加速，以高效、稳定、轻量化的特性，满足个人日常使用与轻量批量转换需求。
项目命名为「棱镜」，寓意如同光线折射般，实现各类媒体格式的自由转换、无损解析、精准适配。

---
🚀 核心特性
- 硬件加速渲染：原生支持 NVIDIA CUDA、Intel QSV、AMD VCE 硬件编解码，大幅降低 CPU 占用，提速 3–8 倍，大文件转换不卡顿、不发烫
- 全品类媒体转换：全覆盖日常使用的音频、视频、图片主流格式，无需多款工具切换，一站式完成转换
- 轻量化重构优化：基于 FFmpeg 源码二次精简开发，剔除冗余模块，启动更快、体积更小、资源占用更低
- 高质量转换算法：智能码率适配、分辨率自适应、无损压缩算法，平衡转换速度与媒体画质，杜绝模糊、失真、音画不同步问题
- 批量转换支持：支持多文件批量队列转换，自动重试异常任务，大幅提升批量处理效率
- 极简使用体验：简化复杂 FFmpeg 原生参数，封装可视化/简易指令操作，新手零门槛上手
- 高兼容性：支持主流操作系统，适配不同设备硬件环境，自动识别硬件加速模式

---
📂 支持格式列表
🎬 视频格式
输入/输出：MP4、MOV、AVI、FLV、MKV、WMV、WebM、TS、M4V 等主流视频格式
🎵 音频格式
输入/输出：MP3、FLAC、WAV、AAC、OGG、M4A、WMA、APE 等主流音频格式
🖼️ 图片格式
输入/输出：JPG、PNG、GIF、BMP、WEBP、TIFF、HEIC 等主流图片格式，支持动图无损转换

---
⚙️ 硬件加速支持
Prism 自动检测设备硬件环境，智能启用最优加速方案，无需手动配置：
- NVIDIA：CUDA 硬件编解码
- Intel：QSV 快速同步视频
- AMD：VCE / AMF 硬件加速
- 通用兼容：无独立显卡设备自动回落高性能软编码，保障转换稳定性
